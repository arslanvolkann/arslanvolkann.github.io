# Volkan Arslan — personal site

Personal site of Volkan Arslan, mechanical / opto-mechanical design engineer: profile, experience, skills and engineering tool posts.

- `index.html` — home page
- `posts/` — posts
- `tools/athermal/` — Athermal Bond Calculator (demo)
- `assets/` — shared theme, styles and scripts

Static site (plain HTML/CSS/JS) for GitHub Pages; no build step on GitHub. The interface is available in English, Turkish and German.
